# Neuron Graph RAG Wiki

Neuron Graph RAG（NGR）は、ハイブリッド検索、型付き知識グラフ、決定論的な活性伝播、成功フィードバックを、一つの観測可能な RAG パイプラインとして検証するプロジェクトです。現段階は MVP であり、実運用での有効性はまだ検証されていません。
